Como transformar este protótipo no arquivo do Figma

  1. Abra este arquivo no Chrome e tire um print de cada um dos 4 quadros (Tela 1 a Tela 4).
  2. No Figma, crie um arquivo chamado ConciliaCard — Sprint 1 e um frame por tela (Desktop 1440 x 1024).
  3. Cole o print como referência de fundo e redesenhe os elementos com os componentes do Figma (retângulos, textos, auto layout). Paleta: azul #1D4E89, fundo #F4F6FA, borda #E2E6EF, verde #1B7F4B, amarelo #A86B00, vermelho #B32D2D. Fonte: Inter ou Arial.
  4. Use o Prototype do Figma para ligar: Tela 1 → Tela 3 (botão Entrar), Tela 1 → Tela 2 (aba Criar conta), Tela 3 → Tela 4 (botão Conciliar).
  5. Publique com Share → Anyone with the link → can view e entregue o link no Teams.
